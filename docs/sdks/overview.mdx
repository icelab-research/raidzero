The SDKs are open source at [github.com/icelab-research/raidzero](https://github.com/icelab-research/raidzero).

Package versions are listed on each language page. TypeScript is at `0.1.2`;
the other published manifests remain at `0.1.1`. Pin the version you install.

The SDKs cover ingest, tasks, assets, search, prefixes, monitor CRUD, paginated
monitor events, and high-level alerts. Method names follow each language's
naming convention. See [Observability and alerts](/sdks/observability) for the
polling and cleanup contract.

Building in C++? There's no published package — see the [C++ example](/sdks/cpp) for a single-header helper you can copy into your project.

Profiling a Go service? The
[go-signoz helper](https://github.com/icelab-research/raidzero/tree/main/go-signoz)
exports process CPU capacity for SigNoz alerting.

## Authentication

SDKs send your API key as an `Authorization: Bearer sk_live_...` request header. Keep it in an environment variable and avoid committing it to source control.

## Error handling

SDKs use three error categories:

| Error | When it's thrown |
| --- | --- |
| API error | The server returned a non-2xx response. Carries `code`, `message`, and `status`. |
| Request timeout | A single HTTP request exceeded the configured timeout. |
| Poll timeout | `pollTask` ran out of time before the task reached `ready` or `failed`. |

Error codes from the API:

| Code | Meaning |
| --- | --- |
| `unauthorized` | Invalid or missing API key. |
| `not_found` | Asset or task ID doesn't exist. |
| `bucket_not_connected` | S3 source used before bucket is configured. |
| `s3_access_denied` | SDK can't read from the specified S3 key. |
| `unsupported_format` | File type isn't supported for indexing. |
| `file_too_large` | Upload exceeds the size limit. |
| `rate_limited` | Too many requests. Back off and retry. |
